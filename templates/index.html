Recursion

Master Recursion: Functions That Call Themselves

What is Recursion?

Recursion is when a function calls itself to solve a smaller version of the same problem. Every recursive function needs a base condition to stop the recursion, otherwise it would run forever!

🔄 Recursive Call: Function calls itself 🛑 Base Condition: Stops recursion 📚 Call Stack: Memory for each call ↩️ Return: Values bubble back up

Linear Search vs Binary Search

🔍 Linear Search

  • Approach: Sequential search
  • Time: O(n)
  • Space: O(1)
  • Data: Works on any array
  • Use when: Small datasets, unsorted data

⚡ Binary Search

  • Approach: Divide and conquer
  • Time: O(log n)
  • Space: O(1)
  • Data: Requires sorted array
  • Use when: Large sorted datasets
